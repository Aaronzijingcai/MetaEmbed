# P1: Optional Analyses

These experiments refine interpretation after the P0 evidence is complete:

1. alternative cross-granularity gain definitions;
2. alternative importance estimators;
3. pairwise granularity combinations;
4. prefix-level evaluation;
5. hyperparameter sensitivity;
6. diagnostics, failure cases, and seed summaries.

Each family remains isolated and uses the same status gate as P0.
